# Pocket XR 1.5.2 (182): 16 KB memory pages, 2026-11-17

Status: **built, not uploaded.** It replaces 1.5.1 (181) in the Production draft in Play Console, which Mike has put on
hold. Nothing has been sent for review.

Why: Play Console's review step refused 1.5.1 (181) for Production with "Your app does not support 16 KB memory page
sizes". Three of the bundle's eleven native libraries had 4 KB LOAD alignment:

| Library | Where it comes from | Fix |
| --- | --- | --- |
| libflipspaces_frametimes.so | app/src/main/cpp (CMake, NDK r27) | `-DANDROID_SUPPORT_FLEXIBLE_PAGE_SIZES=ON` in app/build.gradle.kts |
| libpocketxr_alvr.so | app/src/main/cpp (CMake, NDK r27) | the same |
| libalvr_client_core.so | jniLibs, ALVR 21.0.0-dev14 built in WSL (docs/PCVR-PLAN.md) | rebuilt from the same source with `-Wl,-z,max-page-size=16384`, then `llvm-strip` |

The rebuilt ALVR library has the same 44 `alvr_` exports (including the local `alvr_get_total_prediction_offset_ns`),
the same dependencies and the same size as the 8 November build; only its alignment changed. The old copy is kept in WSL
as `~/alvr-build/libalvr_client_core-4k-2026-11-08.so`.
