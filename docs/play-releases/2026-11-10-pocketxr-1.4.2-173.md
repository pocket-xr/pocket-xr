# Pocket XR 1.4.2 (173): closed testing release, 2026-11-10

Status: **committed to Closed testing - Alpha** through the API, replacing 1.4.1 (172). The edit was committed without
`changesNotSentForReview`, so Play takes it for review itself; check Publishing overview in Play Console. Production

in 2D with Spatial Anchor off. Checked on Mike's Aura with the signed build before release.
