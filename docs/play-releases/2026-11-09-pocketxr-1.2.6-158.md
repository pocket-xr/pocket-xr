- Play Console no longer has an API access page (the URL redirects to Home), so there is no linked Cloud project. Cloud Console as connect@mikehaye.com asked for a password check, which a worker cannot do.
- So the service account was made with Mike's gcloud login in the Jarvis project: **pocketxr-play-release@jarvis-mhaye.iam.gserviceaccount.com**. androidpublisher and iamcredentials APIs were enabled in jarvis-mhaye, and mhaye20@gmail.com has Service Account Token Creator on that account only.

- Play Console, Users and permissions: the service account was invited with access to **Pocket XR only**, with "Release apps to testing tracks" (plus the two view permissions Play adds by default). No production, store presence or account permissions. It shows as Active.
