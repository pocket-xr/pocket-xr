# Pocket XR 1.3.4 (170): closed testing release, 2026-11-10

Status: **committed to Closed testing - Alpha** through the API, replacing 1.2.11 (163), which was in review. The edit
was committed without `changesNotSentForReview`, so Play takes it for review itself; check Publishing overview in Play
Console. Production and the store listing were not touched.

Why now: 1.3.3 added Save and Restore settings, so testers can move from the GitHub build (a different signing key,
so an uninstall) without losing their setup. The Play build needs the restore side.
